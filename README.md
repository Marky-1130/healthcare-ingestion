# Healthcare Patient Ingestion System

A production-grade healthcare ingestion microservice built with:

- FastAPI
- PostgreSQL
- Celery
- Redis
- Docker
- LocalStack
- Alembic

The system ingests healthcare patient visit records, converts them into CSV files, uploads them into S3 via LocalStack, and asynchronously processes them into normalized PostgreSQL tables.

---

# System Architecture

```text
Client
   ↓
FastAPI API
   ↓
CSV Generation
   ↓
LocalStack S3
   ↓
Celery Worker
   ↓
PostgreSQL
```

# Ingest Patients

## Endpoint

```http
POST /patients/ingest
```

## Request Body

```json
[
  {
    "mrn": "MRN-1001",
    "first_name": "John",
    "last_name": "Doe",
    "birth_date": "1990-02-14",
    "visit_account_number": "VST-9001",
    "visit_date": "2024-11-01",
    "reason": "Annual Checkup"
  },
  {
    "mrn": "MRN-1001",
    "first_name": "John",
    "last_name": "Doe",
    "birth_date": "1990-02-14",
    "visit_account_number": "VST-9002",
    "visit_date": "2024-11-15",
```

# CSV Processing Workflow

1. API receives JSON payload
2. Payload converted into CSV
3. CSV stored locally in `uploads/`
4. CSV uploaded to LocalStack S3
5. Celery task triggered
6. Worker downloads CSV from S3
7. Records processed into PostgreSQL

---

# Database Schema

# Patients Table

| Column | Description |
|---|---|
| id | Primary Key |
| mrn | Unique MRN |
| created_at | Creation timestamp |

---

# Persons Table

| Column | Description |
|---|---|
| id | Same as Patient ID |
| first_name | First name |
| last_name | Last name |
| birth_date | Birth date |

---

# Visits Table

| Column | Description |
|---|---|
| id | Primary Key |
| visit_account_number | Unique visit identifier |
| patient_id | Foreign key |
| visit_date | Visit date |
| reason | Visit reason |

---

# Validation Rules

## MRN Rules

- Must start with `MRN-`
- Must be unique

## Visit Rules

- Visit account number must start with `VST-`
- Visit account number must be unique

## Payload Rules

- Empty payloads are rejected
- Required fields enforced
- Invalid dates rejected
